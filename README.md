# Roast the Smart Fridge: One Line, Best Laugh Wins

One line roasting a smart home gadget, for the make.fun bounty
`u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9`.

## Entry

> My washing machine finished an hour ago and still beeps every five minutes, like it wants applause for a job I already paid it to do.

133 characters, one line. The washing machine's end-of-cycle beep that
never stops — applause for a job it was already paid to do.

## How it works

`main.py` (Python stdlib only) validates the line — 1–160 characters,
a single line, no leading or trailing whitespace — and writes it to
`/output/entry.txt`.
